# Escritorio docente interactivo

Objetivo: mejorar toda la superficie docente con OpenDesign frontend-design, redesign-skill y animate. Conservar identidad crema/naranja/verde, datos y flujos locales. No cambiar reglas educativas ni contratos API.

- [x] Pruebas previas de filtros de inicio/sesiones/alumnos, permisos, diálogos y responsive.
- [x] Navegación con barra contextual, búsqueda y sidebar plegable; indicadores basados en datos actuales.
- [x] Dashboard filtrable por salón con tarjetas que llevan a acciones, comparación visual y apoyo desplegable.
- [x] Sesiones con búsqueda, grado, vista lista/cuadrícula y formulario con respuesta visual, referencia documental y guardado confirmado.
- [x] Aulas con búsqueda, estado, orden y switches etiquetados con confirmación persistente.
- [x] Diálogos accesibles, Escape, foco restaurado; respuestas de Reglita y temporizadores limpios.
- [x] Diseño responsive y movimiento reducido; navegador, tipos, build, tests y revisión independiente. Publicar según autorización vigente.

El acceso docente también permite personalizar el nombre con respuesta visual de Reglita. Verificación: 19 pruebas de regresión de interfaz y 11 del docente, más 66 de motor/GameSpec, tipos y build. Revisión independiente sin problemas importantes.
