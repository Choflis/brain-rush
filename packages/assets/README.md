# packages/assets

Biblioteca de ilustraciones SVG etiquetadas por área, grado y tema. El modelo de IA solo puede referenciar assets de esta biblioteca (ver docs/especificacion/03-arquitectura-tecnica.md, sección 6).

Reglas:

- Cada asset tiene un `id` estable, etiquetas y licencia.
- Los íconos de terceros se usan solo con licencia verificada y se registra su atribución aquí.
- Mascota y escenarios: diseño original del equipo.
